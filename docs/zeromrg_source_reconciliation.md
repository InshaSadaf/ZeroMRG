## Zero-shot paper fidelity

The supplied `paper/2026 medical report generation.pdf` was inspected directly (text extraction retained under the reconciliation directory). Section 3 describes frozen MCLIP encoders, text-only decoder reconstruction and prompt enrichment; Section 4 provides SGD .001/momentum .99/batch6, 500 COV-CTR prompts and 50-epoch validation-BLEU patience. It does not specify the decoder internals, tokenizer, split seed, exact revisions, raw-versus-unit prompt preprocessing, greedy search or maximum sequence length. These remain implementation assumptions, not paper-stated specifications.

The named Hugging Face M-CLIP checkpoint is the **text** tower with an OpenAI CLIP ViT-L/14 companion image tower, sharing a 768-D projected space ([official model card](https://huggingface.co/M-CLIP/XLM-Roberta-Large-Vit-L-14)). Dimensions alone do not establish alignment for an arbitrary substituted vision model. Gate 1 uses the named companion tower with RGB/canonical CLIP 224x224 preprocessing, evaluation mode, all image/decoder gradients disabled, visual parameter dtype respected and output promoted to float32. No vision fine-tuning is introduced.

For image vector `v` and prompt rows `P`, paper Eq. 6 is `softmax(v P^T / sqrt(768)) P`; Eq. 5 is the L2-normalized residual `normalize(v + attended_prompts)`. The runtime implements precisely this scaled dot product, softmax over 500 prompts, residual and final L2 normalization. It does not replace the operation with cosine nearest-neighbor retrieval, generic text prompting, temperature tuning or separately normalized prompt rows. Raw prompts are an existing source assumption whose historical feature provenance is preserved by hashes.

Greedy generation starts at BOS, takes the next-token argmax under the causal mask, pads completed examples and stops at EOS for all examples or length160 including BOS. Postprocessing removes PAD/BOS, stops at EOS and joins punctuation under the historical rule. It does not remove generated UNK by inventing text. Generation/length choice is documented because the paper is silent.

Fidelity limits: historical text initialization/freeze evidence is incomplete in exported source; metadata gives model name but not exact revision/package checksum. Normalized prompt vectors and cached report vectors are extremely close but not identical, so their exact common encoding run is unverified. The image-conditioned diagnostic has not run on Kaggle, and is presently blocked by missing selected-best weights. No zero-shot result or final evaluation is claimed. The modular normalized-prompt/scaled-decoder path must not be used with historical checkpoints.
