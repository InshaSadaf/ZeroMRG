Working technical note, 2026-10-12, D-019. Owner review is required before using this prose in a research publication. The owner has approved prioritizing faithful architecture/methodology and evaluation on the **existing modified COV-CTR dataset**, without claiming numerical equivalence to the paper. Further decoder training is deferred. This note does not authorize evaluation or a Kaggle submission.

The local source is `data/COV-CTR with English reports.zip`, containing a `COV-CTR/` image directory and `reports_ZH_EN.csv`. The English target field is `reports_En`. The annotation file has 726 rows and 720 distinct image identifiers. Six identifiers have conflicting duplicate annotations; those keys are excluded rather than resolved arbitrarily. The archive contains 746 physical image files, including 26 without annotations. The retained canonical population is **714 valid image-report pairs**. These observations are recorded in the [dataset audit](../data/processed/cov_ctr/validation_summary.json) and [checkpoint-family validation audit](../artifacts/reconciliation/gate1_20261010_checkpoint_audit/epoch90/validation_audit.json), and reconciled against the raw archive in the [recovery inspection](../artifacts/gate4b/recovery_20261012/inspection.json) and corrected notebook's [identity contract](../notebooks/gate4b/image_conditioning/dataset-contract.json).

The authoritative checkpoint-associated CSV memberships remain **571 training / 71 validation / 72 test**. Counts alone do not identify a split: the modular `data/processed/cov_ctr` family has different memberships despite the same counts, as documented in the [governance reconciliation](evidence/phase1_governance_review.json). Use the historical checkpoint CSVs, vocabulary368 and original **500 ordered training-prompt IDs**. Nothing in this recovery regenerates splits, selects new prompts, or changes the exclusions. The contract pins the full CSV hashes and ordered ID fingerprints. The raw annotation hash is `bfb892f3453276f652d8a14dcfdc6f215dd3eecd435394a5c05bdb8209a04489`; all746 image content hashes are pinned. The original historical report normalization is NFC plus whitespace collapse and strip; local contract construction verifies equality with the validated checkpoint targets. Runtime mount resolution hashes report bytes for identity and does not parse clinical references for generation or scoring.

The supplied paper's §4.1 describes **728 COV-CTR images**; see the retained [paper extract](../artifacts/reconciliation/gate1_20261010_remote/paper_text.txt), sourced from the supplied PDF. The local 714-pair population is therefore different. The paper's original files, exact memberships, per-record annotations, preprocessing history and exclusion handling have not been independently verified against this archive. Do not infer which original records were added, removed or edited, or recreate an original dataset from the reported total. The owner explicitly identifies the local dataset as modified; the precise edit history relative to the original release remains unverified.

Exact numerical replication is also limited by different populations/memberships, missing historical epoch85 weights, incomplete historical stopping, unverified historical encoder/cache revisions, and the remaining metric-contract work. The current physical epoch90 decoder is a preserved available checkpoint, not a replacement labelled as epoch85. Its **54.21140850351637 BLEU-4 is text-reconstruction validation**, not image-to-report test performance. No image-to-report score is produced by this recovery. Future results should be labelled evaluation on the documented modified dataset; the paper's scores may be contextual comparisons, with these differences disclosed.

The methodological components retained in the current pipeline are text-only decoder reconstruction with frozen M-CLIP/XLM-Roberta-Large-Vit-L-14 features and **zero paired image-report supervision**, the frozen companion OpenAI CLIP ViT-L/14 at inference, the fixed training-report prompt bank, original scaled prompt attention/residual image addition/L2 enrichment, and the historical six-layer Transformer/vocabulary/greedy decoding to maximum160. These components are source-verified; the earlier [Gate4 single-image execution](zeromrg_gate4_execution.md) verified the frozen image-to-report mechanics. The current five-image sensitivity diagnostic remains unexecuted after correction. Architectural implementation, image sensitivity, semantic grounding and clinical correctness are distinct claims; none establishes the others automatically.
